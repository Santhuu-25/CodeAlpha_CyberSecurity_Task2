# 🛡️ PhishGuard – Real-Time Phishing Detection

PhishGuard is a real-time web-based cybersecurity application designed to analyze URLs and text messages for potential phishing indicators.

The application uses a Flask backend, rule-based detection engine, and SQLite database to provide dynamic phishing risk analysis and scan history.

## 🚀 Features

- Real-time URL scanning
- Real-time message analysis
- Dynamic phishing risk score
- Risk levels:
  - Low Risk
  - Suspicious
  - High Risk
  - Critical
- Detection of potential phishing indicators
- Detailed analysis results
- Real-time dashboard statistics
- Scan history
- SQLite-based persistent storage
- Flask REST APIs
- Responsive cybersecurity dashboard
- Loading and error handling
- No page reload required after scanning

## 🏗️ Technology Stack

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- SQLite
- REST API
- Rule-Based Security Analysis
